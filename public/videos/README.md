# Lab #07 — Directorio de Video

Coloca aquí tu archivo de video con el nombre exacto: `demo.mp4`

## Requisitos recomendados
- **Formato:** MP4 con códec H.264 (compatible con todos los navegadores modernos)
- **Resolución:** 1280×720 (720p) o 1920×1080 (1080p)
- **Duración:** 5–20 segundos (ideal para scrubbing)
- **Tamaño:** Máximo 50 MB para carga rápida
- **Contenido ideal:** Animación de producto, morphing 3D, timelapse de código, visualización de datos

## Instrucciones

1. Copia tu video a esta carpeta: `public/videos/demo.mp4`
2. Abre el portfolio en el navegador
3. Navega a **Experimentos → #07 Video Scrubbing**
4. El video cargará automáticamente

## Script Python (Opcional)

Si quieres procesar el video antes (optimizar tamaño, extraer frames):

```bash
# Desde la raíz del proyecto
python video_to_frames.py --input ruta/a/tu/video.mp4
```
